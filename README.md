**Logistics Operations Development Manager** · BI & automation builder · Bangkok, Thailand 🇹🇭

## 🔧 What I build

- **End-to-end report automation:** data extract → transform → scheduled delivery by email or SharePoint, with no manual steps
- **RPA for legacy systems:** Power Automate Desktop flows for systems that have no API
- **Excel + Power Automate hand-offs:** VBA/Office Scripts that work with cloud flows through trigger files and idempotent audit columns
- **BI & dashboards:** Power BI models, DAX and Power Query pipelines for operations KPIs
- **Small internal web tools:** lightweight FastAPI + SQLite apps for team workflows

## 💡 How I work

- **Accuracy over speed:** whoever builds a report doesn't sign it off. Every total is re-checked against the source.
- **Design for re-runs:** automations should be safe to run twice (idempotent).
- **Document as I go:** every project ships with a diagram and a plain-language "how it works".
